# Minimal Portfolio

A responsive, buildless HTML, CSS, and vanilla JavaScript portfolio. Open dist/index.html directly, or serve dist with any static web server.

## Personalize
- dist/index.html: search PERSONALIZE for the name, portrait, bio, stats, project details, and contact links. All content is illustrative.
- Replace every generic GitHub and LinkedIn destination with your profile URL.
- Replace each data-demo project anchor with its real URL, and remove data-demo. The current links show an honest concept-project dialog.
- dist/script.js: change CONTACT_EMAIL. The form opens an email draft; it requires an email application and does not send or store messages itself. For server delivery, connect your own form endpoint.
- dist/styles.css: theme colors and fonts are in :root. The accent is warm gold, with a darker shade for readable text.
- Replace the external Unsplash portrait and project photos with your own optimized files and meaningful alt text. Google Fonts and Unsplash require network access; fonts have system fallbacks.
- Update the page title, description, Open Graph metadata, and footer.

## Included
Responsive mobile navigation, active section tracking, accessible modal previews, native form validation, reduced-motion support, progressive scroll reveals, keyboard focus styling, semantic landmarks, and lazy-loaded project photography. No dependencies or build step.
